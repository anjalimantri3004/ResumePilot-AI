# ResumePilot AI

AI-powered ATS Resume Analyzer built with Streamlit.

## Features

* ATS Resume Score
* Resume vs Job Description Skill Matching
* Missing Skills Detection
* Tailored Resume PDF
* AI Cover Letter Generator
* Cold Email Kit Generator
* Chrome Extension for Job Description Capture

## Tech Stack

* Python
* Streamlit
* Pandas
* PyMuPDF
* BeautifulSoup
* ReportLab
